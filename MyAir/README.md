# # MyAir 🚀 🌬️

App nativa de iOS diseñada para monitorear y visualizar la **calidad del aire en la Zona Metropolitana de Monterrey** en tiempo real, utilizando experiencias de **Realidad Aumentada (AR)** para concientizar sobre la contaminación ambiental de una manera inmersiva.

## Características Principales ✨
* 📱 **Visualización Interactiva:** Interfaz moderna y fluida desarrollada con SwiftUI.
* 🕶️ **Realidad Aumentada:** Integración con **ARKit** y **RealityKit** para proyectar datos volumétricos, partículas virtuales e indicadores de contaminación directamente en el entorno real del usuario a través de la cámara.
* 📍 **Enfoque Local (Regiomontano):** Diseñado específicamente para mapear la información proveniente de las estaciones de monitoreo clave de Monterrey (San Bernabé, Obispado, Santa Catarina, Pastora, Apodaca, etc.).
* 🔒 **Permisos del Sistema:** Configuración nativa y segura de acceso a la cámara mediante las llaves de privacidad correspondientes (`Privacy - Camera Usage Description`).

## Tecnologías Utilizadas 
* **Lenguaje:** Swift 5.10
* **Framework de Interfaz:** SwiftUI
* **Frameworks de AR:** ARKit, RealityKit
* **Despliegue mínimo:** iOS 17.0+
